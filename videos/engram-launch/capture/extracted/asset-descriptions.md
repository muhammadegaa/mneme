# Asset inventory

No web assets were captured — this is a no-capture, script-driven product demo.

The "assets" are REAL terminal output captured from the running product, to be
rendered as styled monospace/code blocks (the authenticity is the point — every
"it works" beat shows real output, nothing faked):

- `engram_inspect` — the developer's live memory (5 memories, null_check seen 18×), backend=qwen
- `engram_review` — the grounded catch over MCP, live on Qwen
- `demo:catch` — learn a real unseen repo (codehere) → catch a fresh `var` diff, grounded + signature-verified
- `bench` — the A/B/B+/C benchmark table (forgetting drives contradiction acc + stale leakage)
- `proof` — the live Qwen/DashScope-on-Alibaba-Cloud proof line

Brand identity (from the product's Memory Inspector): editorial dark theme, cream
ink on near-black canvas, coral (#FF5C57) reserved for catches/mistakes, serif
display (Fraunces) + monospace (JetBrains Mono) for code.
